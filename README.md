# PCI Committee Deck

Navigable HTML presentation of **PCI (Price Competitiveness Index)**, Astara Intelligence: nine scenes from "From data to decision" to the PCI platform and use cases.

Published at https://alvarolopez-commits.github.io/PCI-COMMITTEE-WEB/

- `→`, `Space`, `Enter` or click: next · `←`: back · `F`: full screen.
- Fonts (Manrope, and Inter for numbers) load from Google Fonts, so the room needs an internet connection.
- Static page: `index.html` plus `assets/` (backgrounds, brand, flags, use-case backgrounds and icons, platform screenshots). Flags are from flag-icons (MIT).
